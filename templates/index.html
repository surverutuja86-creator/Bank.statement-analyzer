Understanding The Solution

Why Smart Statement Analysis Matters

Manual auditing of monthly bank statements is slow, error-prone, and hides critical spending leaks.

Problem Statement

Why manual statement analysis is difficult: Standard bank statements come in cryptic CSV or Excel formats with inconsistent narrations (`UPI/1920/SWIGGY`, `ACH DEBIT HDFC`).

  • Floating Point Errors: Standard spreadsheets accumulate binary rounding errors when calculating large currency balances.
  • Hidden Recurring Debits: Duplicate charges and silent subscription auto-renewals get overlooked in long transaction lists.
  • Time Consuming: Manual ledgering takes hours every month per bank account.
  • Lack of Pattern Matching: Difficult to separate UPI P2P payments from P2M merchant expenses.

Objectives & Benefits

Project Objectives: Build an automated, local-first Python & SQLite engine that standardizes input statements, enforces exact monetary precision, and delivers instant insights.

  • Exact Decimal Math: Python `Decimal` data type ensures zero precision loss down to the cent/paisa.
  • Intelligent Rule Classifier: Auto-flags Salaries, EMIs, Subscriptions, and UPI handles instantly.
  • Local Database Storage: Complete privacy with SQLite serverless relational storage.
  • Instant Anomaly Shield: Detects duplicate debits within 48h and sudden spending spikes.

Core Capabilities

Comprehensive Financial Analysis Engine

12 powerful modules working together to turn complex statements into clear actionable intelligence.

CSV/Excel Upload

Parses multi-bank CSV and Excel statement sheets cleanly, auto-detecting date formats, narration headers, credit/debit columns, and account balances.

Auto Categorization

Intelligent pattern-matching engine that maps raw transaction descriptions into clear categories: Groceries, Food & Dining, Utilities, Shopping, and Investments.

UPI Detection

Parses complex VPA handles (`@okaxis`, `@ybl`, `@paytm`) to distinguish P2P personal transfers from P2M merchant payments.

Salary Detection

Identifies recurring monthly payroll credits, corporate salary keywords (`ACH CREDIT`, `PAYROLL`), and employer bonus payments.

EMI Detection

Pinpoints monthly recurring loan repayments, tenure tracking, credit card EMIs, and auto-debit mortgage schedules.

Subscription Detection

Detects recurring digital SaaS services, streaming platforms (Netflix, Spotify, AWS, Prime), and membership fees.

Duplicate Debit Detection

Automated anomaly flagger highlighting identical debit amounts executed within short 48-hour time windows.

Spending Spike Detection

Outlier detection algorithm flagging sudden high-value debits exceeding 2.5x the rolling 30-day average transaction size.

Monthly Expense Analysis

Generates categorical spending distribution, cash flow velocity, savings rate, and month-over-month burn rate metrics.

SQLite Storage

Embedded, zero-configuration relational database storing normalized transactions, upload audit logs, and custom rules.

Decimal Precision

Uses Python's native `Decimal` module for all financial arithmetic, completely eliminating IEEE-754 binary floating-point rounding errors.

Rule-Based Classification

Configurable priority keyword mapping allowing users to define custom rules for merchant names, tags, and category overrides.
